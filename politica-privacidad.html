Política de Privacidad de TL BROADCAST

Última actualización: 3 de octubre de 2026

Esta Política de Privacidad explica cómo TL BROADCAST (en adelante, “la Aplicación”) trata la información cuando una persona utiliza sus funciones de transmisión en vivo, incluyendo el inicio de sesión mediante Facebook cuando dicha función esté habilitada.

1. Información que podemos procesar

  • Datos de inicio de sesión de Facebook: cuando el usuario elige iniciar sesión con Facebook, podemos recibir los datos que Meta autorice para la aplicación, como identificador de usuario, nombre y correo electrónico, si este último es proporcionado y autorizado.
  • Información técnica: información necesaria para que la aplicación funcione correctamente, como versión de Android, información del dispositivo, conexión de red y registros técnicos de errores.
  • Cámara y micrófono: la aplicación utiliza la cámara y el micrófono únicamente cuando el usuario inicia una transmisión o grabación que requiere esos permisos.
  • Configuración de transmisión: determinadas configuraciones introducidas por el usuario, como una dirección SRT, y elementos del tercio inferior, pueden guardarse localmente en el dispositivo para facilitar su reutilización.

2. Finalidad del tratamiento

La información se utiliza para autenticar al usuario, permitir la configuración y ejecución de transmisiones, enviar el contenido a los destinos seleccionados por el usuario, conservar configuraciones locales y mantener la seguridad y funcionamiento de la aplicación.

3. Facebook y Meta

Cuando el usuario utiliza Facebook Login o una función de transmisión hacia servicios de Meta, determinados datos se procesan mediante los servicios de Meta conforme a las autorizaciones concedidas por el usuario y a las políticas de Meta. TL BROADCAST no solicita directamente las credenciales de Facebook.

4. Cámara, audio y contenido transmitido

El contenido capturado por la cámara y el micrófono se utiliza para la transmisión o grabación iniciada por el usuario. La persona usuaria controla cuándo comenzar y detener la transmisión. TL BROADCAST no utiliza la cámara o el micrófono en segundo plano fuera de las funciones que los requieren.

5. Almacenamiento

Las configuraciones que la aplicación guarda localmente permanecen en el dispositivo y pueden eliminarse desinstalando la aplicación o utilizando las opciones de limpieza disponibles en Android, según corresponda. Los datos que se procesen mediante servicios de terceros estarán sujetos también a las políticas de esos servicios.

6. Compartición de información

No vendemos información personal. La información se comparte con terceros únicamente cuando es necesaria para proporcionar una función solicitada por el usuario, cuando el usuario lo autoriza, cuando corresponde a servicios integrados como Meta/Facebook, o cuando exista una obligación legal.

7. Seguridad

Aplicamos medidas razonables para proteger la información procesada por la aplicación. Ningún sistema de transmisión o almacenamiento electrónico puede garantizar seguridad absoluta.

8. Conservación y eliminación

Conservamos los datos únicamente durante el tiempo necesario para las finalidades descritas, salvo que la ley o una obligación legítima exija un período diferente. Las solicitudes de eliminación se atenderán conforme al procedimiento descrito en nuestra página de eliminación de datos.

9. Solicitud de eliminación de datos

Para solicitar la eliminación de los datos asociados con el uso de TL BROADCAST, el usuario puede utilizar la página de eliminación de datos de la aplicación y seguir las instrucciones indicadas allí.

10. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones de la aplicación, los servicios integrados o los requisitos legales. La fecha de actualización se modificará cuando se publique una nueva versión.

11. Contacto

Para consultas relacionadas con privacidad o eliminación de datos, contacte al responsable de la aplicación mediante el correo electrónico configurado en la información oficial de TL BROADCAST.
